GitHubで完全無料AIを動かす3ステップ

① GitHub Token(無料)を取得

GitHubの「Developer Settings ➔ Personal Access Tokens」でトークンを作成します。権限チェックは何も入れなくてOKです。

② 画面のツールで暗号化して埋め込む

右上「設定・キー変更」を開き、内蔵された「暗号化ツール」にトークンを貼ってボタンを押すだけ！生成された文字列をHTML内の EMBEDDED_CONFIG.defaultToken に貼れば完全隠蔽できます。

③ GitHub Pagesで無料公開

GitHubに新しいリポジトリを作成し、このHTMLを index.html として保存。Settings ➔ Pages からメインブランチを選択すれば、1分であなたの専用AIサイトが立ち上がります。
